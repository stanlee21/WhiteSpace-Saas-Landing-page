# WhiteSpace – SaaS Landing Page

## Project Overview

WhiteSpace is a responsive SaaS landing page developed as a front-end practice project. The goal is to recreate the WhiteSpace landing page design from Figma using semantic HTML5 and CSS3, while maintaining a clean, accessible, and responsive user experience across different screen sizes.

The project focuses on translating a UI design into a functional web layout without relying on JavaScript or CSS frameworks.

## Project Objectives

- Recreate the WhiteSpace SaaS landing page based on the provided Figma design.
- Build a mobile-first, responsive layout.
- Practise semantic HTML5 and modern CSS techniques.
- Use Flexbox and CSS Grid for page layouts.
- Maintain consistent styling using CSS variables.
- Ensure the page works on mobile, tablet, and desktop screens.
- Avoid horizontal overflow on screens 320px and wider.

## Technologies Used

- **HTML5** – Page structure and semantic markup.
- **CSS3** – Styling, layouts, and responsive design.
- **Git and GitHub** – Version control and collaboration.
- **Figma** – Design reference.

No JavaScript or CSS frameworks will be used.

## Responsive Design Requirements

The page will follow a mobile-first development approach and be tested at these reference widths:

| Device | Screen Width |
| --- | ---: |
| Mobile | 320px |
| Tablet | 768px |
| Desktop | 1440px |

The layout should also adapt smoothly to intermediate screen sizes without horizontal scrolling.

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/stanlee21/WhiteSpace-Saas-Landing-page.git
   ```

2. Navigate into the project directory:

   ```bash
   cd WhiteSpace-landing-page
   ```

3. Open `index.html` in your browser.

No additional dependencies or installations are required.
